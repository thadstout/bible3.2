Bible Answers 4.0 - Interpretation Discipline Patch

Built on Bible Answers 3.8.

What this update adds:
- Bible-only study protocol, not a doctrinal system.
- Salvation/election/predestination vocabulary discipline.
- Requires context checks before drawing conclusions from terms like chosen, elect, predestinated, all, world, whosoever, believe, and works.
- Broadens salvation-related searches so the app gathers balancing passages before answering.
- Keeps the existing Bible-only restraint: answer only from supplied KJV search results.
- Keeps the prophetic/antichrist connection helpers from 3.8.

Important philosophy:
This patch does not add outside doctrine, commentaries, denominational systems, or internet resources. It adds a study method: gather, compare, check context, identify evidence category, and stop where the supplied Scripture stops.

Deploy:
Upload the full contents to GitHub/Netlify the same way you deployed the working version.
Do not put JavaScript into netlify.toml. The netlify.toml file should remain a Netlify config file.
